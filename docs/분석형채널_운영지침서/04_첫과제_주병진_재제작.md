# 04. 첫 과제: 주병진 편 재제작

## 왜 주병진부터
증거 7개(쇼츠로 이미 제작)와 무릎팍 출처가 확보돼 있어 리서치 비용이 가장 낮다. 공급 공백(사업·장사 각도 개인 채널 0). 단, 시청층 50~60대라 천장 12.5만을 전제로 하고, 제목은 '주병진'보다 '장사'(자영업자)로 건다.

## 순서
1. 사실 확정(1일): 광고 날짜(21/22/24일 불일치), 매출(1,000억/1,600억), 간판 비용(320만 원), 매각 연도(2005/2008), 영업부 입사 일화 원문 타임코드
2. 주장·비유 확정(반나절): 주장 "주병진은 물건을 판 적이 없다, 보게 만들었을 뿐이다" / 비유 "무대와 객석" / 예상 반박 3개 작성
3. 14칸 대본(2일): `docs/영상제작지침서/주병진편_대조분석_및_재설계.md` 4장 뼈대를 기준. 15:00, 8,000~8,500자
4. 녹음(반나절): 본인 목소리. 고백 문장 "저도 조회수 6회짜리 영상을 만든 적이 있습니다"는 선택
5. 자산(2일): 기존 무릎팍 클립을 10초 이하로 재단(14블록), 흑백 컷아웃 20장, 무대/객석·진열대 도식, 재현 광고(보유), 4가지 반응 카드
6. 조립·썸네일(1일): "장사란 무엇인가" 7자
7. 출시(4일): 쇼츠 3개(빚쟁이 함정 / 제임시든 / 꽃무늬 반전) 선행 → 롱폼. 기존 쇼츠 7개 고정댓글에 링크 추가
8. 판정(D+2)

## 하지 말 것
- 랭킹뚝딱(쇼츠 랭킹 채널)에 올리지 않는다. 롱폼 채널 또는 새 채널
- 책 8권 인용, TOP7, "잘 따라오세요", 결말 썸네일
- 방송 영상 30% 초과
