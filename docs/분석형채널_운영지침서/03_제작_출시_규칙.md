# 03. 제작·출시 규칙 (본인 목소리)

## 녹음
- 문단 단위 녹음. 10자 이하 문장은 따로 표시해 끊어 읽기("함정이죠." "얼만데.")
- 클립 직후 감탄("와, 기가 막히죠")은 대본대로 읽지 말고 실제로 놀란 톤으로
- 1인칭 문장은 쓴 사람 말투 그대로. AI 다듬기 금지

## 화면 조립
- 클립 14블록 내외, 각 3~10초, 출처 자막. 원리 구간은 클립 0
- 자체 그래픽: 흑백 컷아웃+타이핑 대사(장면 재연), 도식(선택 박스·레일·무대/객석·진열대), 4가지 반응 비교 카드, 텍스트 카드(통찰·반전 문장), 챕터 카드
- 전체 화면 비중 목표: 클립 30% / 컷아웃 20% / 도식·비교 25% / 텍스트 카드 10% / 캐릭터·기타 15%

## 제목·썸네일
- 제목 5안 중 질문형·24~30자·숫자 1개 포함만 채택
- 썸네일 3안: 단색 배경 + 컷아웃 1 + 7자. "~란 무엇인가" 시리즈명 통일

## 출시 순서
| 일 | 할 일 |
|---|---|
| D-3 | 쇼츠 1(함정 장면, "답은 본편") |
| D-2 | 쇼츠 2(실습 변주 하나) |
| D-1 | 쇼츠 3(반전 문장) |
| D | 롱폼. 쇼츠 3개에 관련 동영상 연결, 고정댓글에 링크. 자동 더빙 켜기 |
| D+2 | 판정표 작성 |

## 48시간 판정표
| 지표 | 통과 | 실패 시 |
|---|---|---|
| 노출수 | 5,000 이상 | 500 이하면 노출 문제: 채널·퍼널 점검, 대본 탓 아님 |
| 클릭률 | 5% 이상 | 3% 이하면 썸네일 교체(B안) |
| 평균 시청 지속 | 40% 이상 | 25% 이하면 콜드오픈 재편집 후 재업로드 검토 |
| 선행 쇼츠 | 채널 바닥의 4배 | 미달 시 훅 교체 |
| 댓글 | 주장에 대한 반박이 달리는가 | 반박 0이면 주장이 약함 |
