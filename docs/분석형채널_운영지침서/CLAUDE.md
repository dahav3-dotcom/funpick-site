# CLAUDE.md — 분석형 인물 영상 작업실 규칙

당신은 이 채널의 제작 직원이다. 영상 하나 = 폴더 하나. 산출물은 전부 영상 폴더 안에 남긴다.
이 채널은 인물 서사(눈물·역경)를 팔지 않는다. 유명인의 능력에서 원리 하나를 뽑아 증명한다.

## 폴더
```
<인물_능력>/
  01_리서치/  사실표.md(날짜·숫자·출처URL·신뢰도), 인용후보.md(본인 발화 20개: URL·타임스탬프·요약·감정), 경쟁체크.md
  02_대본/    주장.md(한 줄+반박 예상), 비유.md, 대본_v1~final.md, 14칸표.md
  03_음성/    본인 녹음 가이드(문단별 분할, 10자 이하 문장 표시)
  04_자산/    clips/(10초 이내, 출처·타임코드), cutout/(흑백 컷아웃), diagram/, cards/
  05_그래픽/  remotion/(도식·텍스트 카드·4가지 반응 비교·챕터 카드)
  06_편집/    타임라인.csv(초 단위), 캡컷 프로젝트
  07_출시/    제목5안.md, 썸네일3안, 설명란.md, 쇼츠3개.md, 판정표.md
```

## 소재 규칙 (하나라도 빠지면 만들지 않는다)
- 인물의 모음·클립 영상이 이미 500만 이상
- 능력이 '위트·말빨·장사·설득·경청·멘탈' 같은 한 단어 욕망으로 번역됨(업무 용어 금지: 마케팅·경영·전술)
- 반박 가능한 주장 한 줄이 있다. 반박할 수 없는 문장("노력했다", "운이 아니다")은 주장이 아니다
- 같은 인물·같은 능력의 10만 이상 분석 영상이 없다(경쟁체크.md에 검색 결과 첨부)
- 본인 발언 자료 15개 이상

## 대본 규칙
- 14칸 공식(02_공식_14칸.md) 순서 고정. 콜드오픈은 '판돈→함정 클립→함정 해부(답 숨기기)→정답 클립→감탄→질문'. 결론을 1분 안에 말하지 않는다
- 분당 540~570자. 문장 평균 30자, 10자 이하 10%. 물음표 40개 이상. "근데" 전환 30회. 1인칭 25회. "여러분"은 대입 장면 6곳에만
- 비유 하나로 끝까지 간다. 4가지 반응 비교(평범/무리수/흉내/진짜) 1회. 실습 변주 6개. 반례 1개. 반론 선제 1회(일부 인정 후 "하지만"). 반전은 78~88% 지점. 예고→총정리→보상. 의미→호명→고백
- 책·논문 이름으로 설명을 대신하지 않는다. 개념은 내 말로
- 모든 숫자·날짜는 사실표에 출처가 있는 것만. 자료 간 불일치는 확정 전 사용 금지

## 화면 규칙
- 방송·경기 클립은 전체의 30% 이하, 클립당 10초 이하, 반드시 "이게 먹히는 이유는" 해설 동반. 스포츠 경기 장면은 사용 금지(도식 재구성)
- 원리 구간(통찰·비유·실습·반론)은 클립 0. 흑백 컷아웃+타이핑 대사, 도식, 캐릭터, 텍스트 카드로만
- 썸네일: 단색 배경 + 인물 컷아웃 1 + 7자 이내. 글자 블록 2개 이상 금지. 결말 스포 금지
- 배경음악은 통찰·반전 두 곳만. 웃음은 클립 안에서만

## 출시 규칙
- 제목 24~30자 질문형 "[인물]은 어떻게 [능력]을 [조건]에 [동사]할까?". TOP n·결론형 금지
- 쇼츠 3개(함정·반전·실습 장면, 각 끝에 "본편") 3일 선행 → 4일째 롱폼. 쇼츠에 관련 동영상 연결
- 설명란: 2줄 요약 → 챕터 → 출처 → "클립은 인용·비평 목적" 고지. 자동 더빙 켜기
- 48시간 판정표(03_제작_출시_규칙.md)를 07_출시/판정표.md에 기록

## 보고 규칙
