# 분석형 채널 운영 지침서 (랭킹뚝딱 주병진 편 운영팀 전달용)

## 왜 이 지침서인가
- 「빚으로 시작해 매출 1,600억… 주병진 천재 마케팅 TOP7」(2026-10-18, 9분)은 14일간 조회 6회였다. 콘텐츠가 평가받은 게 아니라 노출이 없었다. 구독 16명·롱폼 이력 0·쇼츠 채널 정체성(40초 랭킹) 때문이다.
- 그러나 같은 소재를 분석형(분석좌 '탁재훈 편' 방식)으로 다시 만들면 비교 사례상 1.5만~6만이 평타, 상위 8만~30만이 가능하다. 개인 채널 주병진 영상은 구독 553명 채널도 12.5만을 기록했다.
- 이 폴더는 그 전환을 위한 규칙이다. 인물 서사형(셀럽인생형) 지침서와는 다른 종목이므로 섞지 않는다.

## 세 줄 요약
1. 제목은 질문, 썸네일은 7자, 영상은 '주장 하나 + 비유 하나 + 3단계'. TOP n 금지.
2. 방송 영상은 30% 이하·클립당 10초. 원리는 그림으로. 책 인용 0권.
3. 롱폼 이력 있는 채널에서, 쇼츠 3개 먼저 → 롱폼. 올리고 48시간 노출수로 판정.
