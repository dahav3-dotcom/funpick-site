# 05. 분석형 프롬프트 모음 (Claude Code)

## 0. 시작
```
[인물]의 [능력]을 분석하는 15분 영상을 만들 거야. CLAUDE.md 규칙대로.
먼저 소재 통과 심사부터: 유튜브에서 "[인물] 레전드 모음"과 "[인물] 분석 비결 이유 어떻게"를 검색해서 수요(최대 조회)와 공급(10만 이상 분석형 영상 수)을 표로 만들고, 통과/탈락을 판정해 줘. 경쟁체크.md로 저장.
```
## 1. 리서치
```
사실표.md(날짜|사실|숫자|출처URL|신뢰도) 30행 이상, 인용후보.md(본인 발화 20개: URL|타임스탬프|요약|감정) 만들어 줘. 자료 간 숫자가 다르면 불일치 표로 따로.
```
## 2. 주장·비유
```
이 인물의 능력을 설명하는 '통념을 뒤집는 한 문장' 후보 5개와 각 문장에 대한 예상 반박 3개를 써 줘. 반박이 가장 선명한 문장을 고르고, 그 문장을 영상 끝까지 끌고 갈 비유 후보 3개(무대·레일·씨름처럼 일상 사물)를 제안해.
```
## 3. 대본
```
02_공식_14칸.md 시간표대로 15분 대본 v1. 분당 550자. 콜드오픈은 정답을 54초까지 숨기고 함정을 해부할 것. 문단마다 [클립 #/길이] [그림: 컷아웃/도식/카드] 지시 포함. 책 이름 금지. 물음표 40개 이상.
```
```
v1에서 결론이 1분 안에 나오는지, "여러분"이 대입 장면 외에 쓰였는지, 4가지 반응 비교·반례·반론·반전·예고가 있는지 점검표로 보고하고 빠진 칸을 채워 줘.
```
## 4. 자산
```
대본의 [클립] 지시를 전부 뽑아 clips.csv(출처URL|시작|끝|길이|해설 문장)로 만들고 10초 넘는 건 줄여. [그림] 지시는 도식/컷아웃/카드로 분류해서 remotion 컴포넌트 목록을 만들어.
```
## 5. 썸네일·제목·출시
```
제목 5안(질문형, 24~30자, 숫자 1개), 썸네일 3안(단색+컷아웃+7자), 쇼츠 3개 구간(함정/실습/반전, 각 45초 이내, 끝 문장 "답은 본편에"), 설명란, 고정댓글.
```
## 6. 판정
```
유튜브 스튜디오 48시간 캡처를 줄게. 노출수·클릭률·시청 지속·쇼츠 성과를 03_제작_출시_규칙.md 판정표에 넣고 다음 편에 적용할 규칙 수정안을 써 줘.
```
