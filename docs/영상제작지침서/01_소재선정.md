# 01. 소재 선정 지침

## 왜 1·2편은 50만, 4·5편은 1만 이하였나
| | 1편 이주헌 | 2편 원이 정산 | 4편 미나미 엄마 | 5편 리마인 |
|---|---|---|---|---|
| 주인공 인지도 | 화제 인물 | 그룹 최고 인기 멤버 | 멤버(엄마 시점) | 팬덤 |
| 훅의 구체성 | 자본금 1천만 원 | 엄마 소고기 | 두 마디(추상) | 비 맞은 객석 |
| 모르는 사람도 보나 | 창업 서사 → 본다 | 눈물 → 본다 | 팬만 | 팬만 |
| 썸네일 글자 | 2줄 | 2줄 | 2줄 | 4블록 |
핵심: 팬이 아닌 사람도 클릭할 '보편 서사'(창업·실패·가족·돈)가 있어야 50만이 됩니다.

## 소재 점수표 (10점 만점, 7점 미만 폐기)
1. 지금 이유(2점): 최근 30일 내 뉴스 트리거가 있는가 (수상·은퇴·사건·기념일·컴백)
2. 검색 수요(2점): 인물명 검색량이 꾸준한가, 자동완성에 "근황/인생/논란"이 뜨는가
3. 보편 서사(2점): 야구를 몰라도 공감되는 축이 있는가 (돈, 가족, 배신, 재기, 포기)
4. 숫자 자산(1점): 기록·금액·날짜가 많아 리모션 숫자 카드로 만들 거리가 있는가
5. 본인 발화 자산(2점): 유튜브·팟캐스트·기자회견에 본인이 말한 영상이 충분한가 (최소 15개 클립)
6. 반전 한 문장(1점): "진짜 주인공은 ~에 없습니다"류의 뒤집기가 가능한가

## 한 인물 → 여러 편 (시점 분할)
셀럽인생이 리센느 하나로 5편을 만든 방식: 대표 / 멤버 / PD / 가족 / 팬덤.
야구에 적용: 선수 본인 / 그를 뽑은 스카우트·감독 / 라이벌 / 가족 / 팬(응원가·현수막).
단, 첫 두 편은 반드시 '본인' 시점. 주변인 시점은 본인 편이 10만을 넘긴 뒤.

## 금지 소재
- 미성년자가 주인공인 서사, 사망 사고 당사자 가족의 미공개 사정, 재판 중 사건의 유무죄 단정
