# 분석좌 탁재훈 편 재검토: 추가 발견 9가지와 못 한 것
(「분석좌_탁재훈편_해부.md」의 보충. 자막 대본 전문·프레임 150장·댓글 50개·채널 메타데이터 기준)

## 추가 발견
1. **영어 자동 더빙 켜짐.** 오디오 트랙 한국어·영어(미국) 2개, 자동 자막 158개 언어. 검색 결과에 제목이 영어로 뜨는 이유. 설정 하나로 해외 유입.
2. **클립 14블록, 나레이션만 이어지는 구간 중앙값 60초.** 90초 이상 클립 없는 구간 3곳: 3:06~5:26(통찰·레일 비유), 9:20~11:38(육하원칙 실습), 13:49~16:35(목적지·반론). 전부 '원리' 구간이며 곰 캐릭터·실루엣·레일 도식·텍스트 카드로만 버팀. 클립은 증거, 원리는 그림.
3. **문장 356개, 평균 31자.** 10자 이하 9%(리듬용: "함정이죠." "얼만데." "왜 그럴까요?"), 40자 이상 29%(설명 구간).
4. **장치 빈도.** 물음표 47, "근데" 31, "우리" 22, "저는/제가" 26(분석자가 계속 존재), "여러분" 6(대입 장면 3:50·5:33·9:58·15:47·15:53·20:15에만), "자," 10(구간 전환), 숫자 25개(절반이 100%·1초·5% 같은 원리용).
5. **예고→총정리→보상.** 18:16 "터닝 포인트 사건을 보기 전에 1분 정리" → 18:37 총정리 → 19:16 보상. 건너뛰는 총정리를 보게 만드는 장치.
6. **댓글은 주장에 대한 반박이 과반.** 상위 50개 좋아요 6,974 중 재능론 48%, 따라하지 마라 37%, 표정·톤 20%, 분석 칭찬 23%(중복). 반박 가능한 주장이 논쟁을 만들고 논쟁이 댓글을 만든다. 제작자 답글 0, 고정댓글 0.
7. **설명란 태그 0, 링크 0, 챕터만.** 유입은 검색이 아니라 탐색·추천(탁재훈 모음 MBC 1,180만·SBS 640만 옆자리).
8. **채널 템플릿의 진화.** 말빨 편(121만, 2025.9)은 0:52에 "이 영상을 보면 얻는 것들" 목록과 비하인드 예고. 탁재훈 편은 그 약속 목록을 빼고 48초 함정 해부로 대체. 13개월에 121만 → 4일에 97만.
9. **분당 564자, 클립 전환 22초, 웃음 17곳.** 웃음은 클립 안에서만. 나레이션은 웃기지 않고 "왜 웃긴지"만 설명.

## 말빨 편 vs 탁재훈 편 챕터 비교
| 말빨 편(32:37) | 탁재훈 편(21:17) |
|---|---|
| 시작 → 이 영상을 보면 얻는 것들 → 핵심(상위 프레임) → 영화로 보는 비결 → 불리한 상황 뒤집기 → 쉬운 방법 → 고수의 간접 프레임 → 무조건 먹히는 1가지 → 논리 무력화 → 기적의 논리 1가지 → 말빨보다 중요한 것 → 명장면 → 총정리 → 구독자께 여쭤보고 싶은 것 | 시작(함정) → 왜 다를까 → 공통점 → 비유 → 3단계①②③ → 1초 만에 어떻게 → 절대 하지 않는 한 가지 → 총정리 → 숨겨진 진짜 의미 |
공통 뼈대: 핵심 한 줄 → 사례 → 방법 → 더 중요한 것 → 총정리 → 의미. 탁재훈 편은 약속 목록을 함정 체험으로, "여쭤보고 싶은 것"을 제작자 고백으로 바꿈.
