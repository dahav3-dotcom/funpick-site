# 클로드 플랜·한도·크레딧 정리 (2026-11-01 확인 기준)

## 1. 플랜 (2026-10-30 개편 이후)
| 플랜 | 월 요금 | 사용량(Pro 대비) | 5시간 한도 | 월간 API 크레딧 |
|---|---|---|---|---|
| Pro | $20 | 1배 | 있음 | 없음 |
| Max (구 Max 5x) | $100 | 5배 | 있음 | $100 |
| Ultra (구 Max 20x) | $200 | 주간 10배 | 인증 계정은 없음 | $200 |
- 구 Max 20x는 자동으로 Ultra로 전환. "20배"는 5시간 세션 기준 숫자였고 주간 한도는 동일.
- Ultra의 5시간 한도 해제는 계정·결제 이력 기반 자동 인증. 설정 → 사용량에 '현재 세션' 막대가 없으면 인증 완료.
- 주간 한도는 전체 모델 공통 1개 + Fable 전용 하위 한도(주간의 최대 50%). 전체가 100%면 Sonnet도 막힌다.

## 2. 돈이 빠지는 곳 네 가지
| 이름 | 어디서 보나 | 무엇에 쓰이나 | 쓰이지 않는 곳 | 리셋/만료 |
|---|---|---|---|---|
| 플랜 주간 한도 | /usage, 설정→사용량 | claude.ai 앱, Claude Code(터미널·데스크톱) | - | 주 단위(예: 저녁 8시) |
| 사용 크레딧(추가 사용) | 설정→결제→사용 크레딧 | 플랜 한도 초과 시 자동 차감. **월 지출 한도**가 별도로 있어 그 한도에 닿으면 잔액이 있어도 멈춤 | API | 프로모션분은 만료일 있음(2027) |
| 월간 API 크레딧 | platform.claude.com 결제 페이지 | 연결된 콘솔 조직의 API 키로 호출하는 전부: Claude API, Agent SDK, Managed Agents, 플레이그라운드, 내 키를 넣은 외부 앱(Raycast 등), 내가 만든 앱의 사용자 호출 | **Claude Code(API 키를 넣어도 안 됨, claude -p 포함)**, claude.ai 앱 추가 사용, Bedrock·Vertex | 매 결제 주기 리셋, 이월 없음 |
| 클라우드 세션 크레딧 | 설정→사용량 '클라우드 세션 크레딧' | claude.ai/code 클라우드 세션 | 터미널 Claude Code | 만료일 명시(예: 11/5), 다 쓰면 플랜 한도로 전환 |

## 3. 자주 생기는 상황
- "주간 한도 7% 남았는데 멈춤": 전체 막대가 100%이고 7%는 Fable 하위 한도. 사용 크레딧의 월 지출 한도도 닿은 상태 → 월 지출 한도 올리기 또는 리셋 대기.
- "클라우드 세션은 되는데 터미널은 안 됨": 클라우드 세션 크레딧이 남아 있기 때문. 만료 전까지 무거운 작업은 클라우드에서.
- "API 크레딧 $200을 못 쓰고 만료": Claude Code에서는 못 쓴다. 플레이그라운드, Agent SDK 스크립트, 내 키를 넣은 앱에서 소진.

## 4. Claude Code 운영 팁
- 잠깐 멈춤: Esc 한 번(대화 유지). Ctrl+C 두 번은 종료. Esc 두 번은 이전 메시지로 되돌리기.
- 이어가기: `claude --continue`(마지막 세션), `claude --resume`(목록에서 선택).
- 한도 확인: `/usage`. 모델 전환: `/model sonnet`. 크레딧 설정 이동: `/usage-credits`.
- 긴 작업 날에만 사용 크레딧 토글을 켜고 평소에는 끄면 조용한 차감을 막는다.
