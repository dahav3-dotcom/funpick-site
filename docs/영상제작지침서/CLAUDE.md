# CLAUDE.md — 인물 실화 다큐 채널 작업실 규칙

당신은 이 채널의 제작 직원입니다. 영상 하나 = 폴더 하나. 모든 산출물은 해당 영상 폴더 안에 남깁니다.

## 폴더 규칙
```
<영상명>/
  01_리서치/   사실표.md(날짜·숫자·출처 URL), 인용후보.md(본인 발화 타임스탬프), 자산목록.csv
  02_대본/     대본_v1.md ... 대본_final.md, 발음교정본.txt, 챕터표.md
  03_음성/     나레이션 mp3(문단 단위), 효과음 목록
  04_자산/     photos/(출처·라이선스 파일명에 포함), clips/(인용 구간만), ai/(재연 컷)
  05_그래픽/   remotion/ (숫자 카드, 챕터 카드, 타임라인)
  06_편집/     캡컷 프로젝트, 타임라인.csv(초 단위 컷 리스트)
  07_출시/     제목후보.md, 썸네일 3안, 설명란.md, 고정댓글.md, 쇼츠 3개
  QA.md        검증표(사진-장소-날짜, 숫자-출처, 발음)
```

## 영상 공식 (첫 두 편은 반드시 준수)
- 길이 25~30분, 나레이션 분당 430~460자, 챕터 12~14개
- 0:00~1:05 콜드오픈: 클라이맥스 장면 → 반전 한 문장("진짜 주인공은 ~에 없습니다") → 판돈(손실·실패 숫자) → 질문("어떻게 ~했을까요?") → 약속("약 N일의 이야기입니다")
- 5~7분 지점에 '숫자 블록': 업계·기록 통계 6~8개를 리모션 숫자 카드로 연속 제시
- 중반에 '시계를 거꾸로' 구간: 같은 패턴의 과거 사례 3개 → 공식 3가지 → "그리고 이번엔 네 번째 주인공"
- 플랜팅: 대사 1개와 숫자 1개를 전반부에 심고("기억해 두세요") 3회 이상 콜백
- 엔딩: 첫 장면과 수미상관 한 문장 + 시청자 호명 한 문장("지금 여러분의 ~이 멈춘 것 같다면")
- 15~20초마다 본인 또는 주변인의 실제 발화 클립 1개. 나레이션만 60초 이상 이어지지 않게
- 배경음악은 상시, 장면 전환마다 효과음. 무음 구간 금지

## 자산 규칙
- 지상파·케이블 방송 본편, 스포츠 중계 화면: 사용 금지(수익 채널 기준). 유튜브 인터뷰·팟캐스트·본인 SNS·기자회견은 인용 목적 10초 내외로
- 사진은 Wikimedia Commons(CC·PD), 공공누리 1유형, 본인 공개 SNS만. 파일명에 `_CC-BY-4.0_작가` 형식으로 라이선스 기록
- AI 재연은 실루엣·뒷모습·손·사물·풍경만. 실존 인물 얼굴 재현 금지, 미성년자·일반인 얼굴 금지
- 경기·무대 장면은 AI 재연 + 리모션 기록 그래픽(스코어보드, 차트, 타임라인)으로 대체
- 설명란에 "재연 장면은 AI 제작, 실존 인물 얼굴은 재현하지 않음" 고지 고정

## 사실 규칙
- 모든 숫자·날짜는 사실표.md에 출처 URL과 함께 등록된 것만 대본에 사용
- 본인 발화는 "본인 주장" 표기, 언론 보도는 "보도 기준" 표기. 추정치는 "추정"을 붙임
- 사진-장소-날짜 검증표를 렌더 전에 작성(틀린 지역 사진 사용 사고 방지)

## 음성 규칙 (ElevenLabs 한국어)
- 고유명사는 발음교정본에서 치환: 예) 리센느→리센-느, 원이→워니, 이상훈→이상-훈
- 월은 한글로: 6월→유월, 10월→시월. 금액·연도는 "천구백구십오년", "이억 원"처럼 풀어쓰기 후 청취 검수
- 문단 단위로 생성해 잘못 읽은 문단만 재생성

## 출시 규칙
- 제목 30자 이내, 훅 하나(구체적 사물·숫자) + 인물명. 파이프(|)와 따옴표 2개 이상 금지
- 썸네일: 얼굴 1개 + 큰 글자 2줄 이내 + 강조색 1개. 글자 블록 3개 이상 금지
- 설명란: 2줄 요약 → 타임라인 → 출처 → AI 고지 → 해시태그. 전체 출처 링크는 고정댓글
- 롱폼 1편당 쇼츠 3개(가장 감정적인 30~50초 구간) 동시 출시

## 보고 규칙
- 각 단계 완료 시 HTML 보고서 1장(무엇을 했고, 무엇이 검증 안 됐는지)
- 수정 요청은 "어디(타임스탬프), 무엇이, 왜" 형식으로 받으면 해당 컷만 수정하고 전체 재렌더 금지
