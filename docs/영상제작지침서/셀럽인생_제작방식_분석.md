## 2. 대본 구조 (29분 기준 타임라인)
- 00:00~01:05 콜드오픈: 클라이맥스(첫 1위) → 반전("진짜 주인공은 무대 위에 없습니다") → 판돈(56억 손실, 11년 전 가수) → 질문("어떻게 1위에 올려 놓았을까요?") → 약속("약 2,000일의 이야기")
- 01:08~05:58 인물 전사: 출생→버클리→데뷔→실패→작곡가 전향→회사 설립(자본금 1천만 원)
- 05:58~08:49 데이터 블록: 업계 통계(6,700개 기획사, 1,182팀, 3.13년, 100억) = 리모션 숫자 카드 집중 구간
- 08:49~17:05 캐스팅과 데뷔, 고난(화장실 하나, 지하 연습실 침수)
- 17:05~18:45 재무제표(자본잠식, 현금 1,300만 원 = 창업 자본금과 같은 액수 → 수미상관 장치)
- 18:45~20:47 "시계를 거꾸로": 역주행 사례 3개(EXID·브레이브걸스·윤하) → 공식 3가지 → "네 번째 주인공"
- 20:47~27:52 역주행 전개(윤성원 PD, 거제 야호, 멜론 1위, 840일 1위, 회사 가치 280억→600억)
- 27:52~29:28 엔딩: "노래가 멈춘 가수 → 다른 노래가 시작" 수미상관 + 시청자 직접 호명("지금 여러분의 꿈이 잠시 멈춘 것 같다면")

반복 장치(플랜팅/페이오프):
- "한 번만 믿어 달라": 4분(김혜수 이사) → 10분(원이 부모) → 18분(원이→메이 부모) → 28분(엔딩). 4분에 "기억해 두세요. 이 말은 앞으로도 몇 번이나 다시 등장합니다"라고 예고.
- 숫자 콜백: 회사 가치 8억(5분, "이 숫자는 나중에 다시 등장") → 280억(22분) → 500~600억(27분). 자본금 1천만 원 ↔ 남은 현금 1,300만 원.
- 강의 '이건희' 대본의 엔딩("오늘 하루쯤은 고맙다고 말해보는 건 어떨까요?")과 같은 공식: 서사 종결 후 시청자에게 한 문장.

## 4. 자동자막으로 드러난 TTS 문제 (ElevenLabs 한국어)
- 고유명사: "리센느"→"리센드/리센", "원이"→"원인/원니/원위", "미나미"→"미남미", "자본금"→"자봉금"
- 이름 오기: 3분 "이주원"(이주헌), 25분 "이지원 대표님"
- 숫자 읽기: "그 해월"(그해 6월?) — 강의의 이건희 영상 자막에도 똑같이 "그 해월"이 나옴. 월 숫자가 빠지는 공통 결함.
→ 대본 단계에서 발음 사전(리센느=리센-느, 원이=워니) 적용, 숫자는 한글로 풀어쓰기("유월") 규칙을 프롬프트에 고정하는 것이 해결책.
