# 인물 실화 다큐 영상 제작 지침서 (클로드 코드용)

'셀럽인생' 채널 5편(이주헌 대표 54만 / 원이 첫 정산 49만 / 윤성원 PD 6.8만 / 미나미 7.7천 / 리마인 1.4천)을
대본·프레임·설명란 단위로 분해해 만든 지침입니다. 강의에서 "리센 대표 30분짜리 영상 만들어 줘" 한 줄로 나온
1편(54만)의 구조를 기준으로 삼고, 뒤 편들에서 무너진 요소를 '하지 말 것'으로 넣었습니다.

## 파일 구성
| 파일 | 용도 |
|---|---|
| CLAUDE.md | 작업 폴더 루트에 넣는 AI 직원 규칙. 클로드 코드가 매번 읽음 |
| 01_소재선정.md | 어떤 인물·어떤 순간을 고를지 점수표 |
| 02_대본구조.md | 29분 대본 뼈대(시간 배분, 장치, 글자 수) |
| 03_제작파이프라인.md | 리서치→대본→TTS→자산→그래픽→조립→QA 단계 |
| 04_프롬프트모음.md | 각 단계에서 클로드 코드에 실제로 치는 문장 |
| 05_야구적용예시.md | 이상훈·선동열·김도영 편 설계안 + 야구 영상 저작권 대응 |

## 사용 순서
1. 새 폴더(예: `야구와인생/`)를 만들고 CLAUDE.md를 루트에 복사
2. `04_프롬프트모음.md`의 [0단계] 한 줄 명령으로 시작
3. 클로드가 `01_리서치/`, `02_대본/` 순으로 산출물을 쌓으면 각 단계 끝의 체크리스트로 승인 후 다음 단계
4. 첫 두 편은 반드시 `02_대본구조.md`의 '1편 공식'을 그대로 따르고, 변형은 3편부터

## 핵심 숫자 (셀럽인생 1편 실측)
- 길이 29분 28초, 나레이션 13,400자(분당 약 450자), 챕터 13개
- 타인 발화(인터뷰·방송 클립) 86회 = 약 20초마다 1개
- 리모션 숫자 카드 약 10장, CHAPTER 카드 13장
- 배경음악 거의 상시(자막 [음악] 태그 71회), 5편은 15회로 줄었고 조회수도 급락
- 플랜팅 대사 1개("한 번만 믿어 달라") 4회 콜백, 숫자 콜백 2종(8억→280억→600억 / 1천만 원↔1,300만 원)
