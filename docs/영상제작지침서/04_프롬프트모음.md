# 04. 클로드 코드 프롬프트 모음

## [0단계] 시작 한 줄 (강의 방식 그대로, 조건만 추가)
```
전 LG 투수 이상훈의 인생 이야기를 28분 다큐 영상으로 만들어 줘.
방향: 야구를 모르는 사람도 공감하게, 돈·가족·재기 축으로. 콜드오픈은 2002년 한국시리즈 6차전 9회말 블론세이브 장면에서 시작해서 "그런데 이 장면의 진짜 이야기는 마운드 위에 없습니다"로 뒤집어 줘.
저작권: 방송 본편·KBO 중계 화면 절대 사용 금지. 유튜브 인터뷰·팟캐스트 본인 발화만 10초 내외 인용. 사진은 Wikimedia·공공누리만. 부족한 장면은 실루엣·뒷모습 AI 재연과 리모션 기록 그래픽으로.
나레이션 ElevenLabs, 배경음악 Suno, 효과음 넣고, CLAUDE.md 규칙 따라서 1단계 기획안부터 보여 줘.
```

## [1단계] 리서치
```
사실표.md를 만들어 줘. 열: 날짜 | 사실 | 숫자 | 출처URL | 신뢰도(보도/본인/추정). 최소 30행.
인용후보.md: 유튜브·팟캐스트에서 본인이 직접 말한 구간 20개. URL, 타임스탬프, 발화 요약, 감정(눈물/웃음/분노) 표시.
```

## [2단계] 대본
```
02_대본구조.md의 13챕터 표대로 대본 v1을 써 줘. 총 13,000자. 문단마다 [화면] [클립 #] [카드] 지시를 달고,
플랜팅 대사 1개와 숫자 1개를 C구간에 심고 E·K·L에서 콜백해. 숫자 블록(D)은 통계 6개 이상.
```
```
v1에서 나레이션만 60초 넘게 이어지는 구간을 찾아서 인용 클립을 끼워 넣고, 콜드오픈을 65초 이내로 줄여 줘.
```
```
발음교정본.txt 만들어 줘: 이상훈→이상-훈, 선동열→선동-열, 6월→유월, 1995년→천구백구십오년. 금액은 전부 한글로.
```

## [3단계] 음성
```
발음교정본을 문단 단위로 ElevenLabs 생성하고, Whisper로 되읽어 원문과 다른 문단 목록을 표로 보여 줘.
```

## [4단계] 자산
```
대본의 [화면] 지시를 전부 뽑아 자산목록.csv로 만들고, 각 행에 조달 방법(클립/CC사진/AI재연/리모션)을 배정해 줘.
AI 재연은 "silhouette, back view, hands only, no face"를 고정 프롬프트로. 사진은 Wikimedia API로 받아 라이선스를 파일명에 넣어.
그리고 사진-장소-날짜 검증표를 QA.md에 써 줘. (지난번 다른 지역 사진이 들어간 사고 재발 방지)
```

## [5단계] 그래픽
```
리모션으로 숫자 카드 10장, 챕터 카드 13장, 연도 타임라인 1장, 상승 그래프 1장을 만들어 줘.
스타일: 검정 배경, 핑크·골드 큰 숫자, 아래 작은 설명. 글자 줄넘김 생기면 폰트 크기 자동 축소.
```

## [6단계] 조립
```
캡컷 프로젝트로 만들어서 보여 줘. 나레이션 트랙, 클립 트랙, 그래픽 트랙, BGM, 효과음 트랙을 분리해.
```
```
효과음들이 왜 이렇게 커? 전체 -8dB. 숫자 카드 등장음만 유지.   ← 강의에서 쓴 수정 지시 방식
```
```
12:40 자막 "10억 이상"이 줄을 넘겼네. 고쳐 주고 다른 데도 줄넘김 있는지 전부 찾아 고쳐. 결과를 HTML로 시각화해서 보고해.
```

## [7단계] 출시
```
제목 5안(30자 이내, 구체 사물·숫자 훅 + 인물명), 썸네일 3안(얼굴 1 + 글자 2줄), 설명란, 고정댓글(출처 전체), 쇼츠 3개 구간 제안.
```

