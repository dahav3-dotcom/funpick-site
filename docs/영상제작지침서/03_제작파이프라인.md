# 03. 제작 파이프라인 (단계별 산출물과 승인 기준)

## 0단계. 한 줄 명령 → 기획안
클로드 코드에 한 줄로 시작하되, CLAUDE.md가 폴더에 있어야 함. 산출: `기획안.md`(훅 3안, 반전 문장, 플랜팅 대사·숫자 후보, 챕터 13개 가제, 예상 자산 목록)
승인 기준: 콜드오픈 5요소가 모두 있는가, 모르는 사람도 클릭할 축이 있는가

## 1단계. 리서치 → 사실표
클로드가 웹 검색으로 `사실표.md` 작성: 날짜 / 숫자 / 출처 URL / 신뢰도(보도·본인·추정) 열 필수.
동시에 `인용후보.md`: 유튜브 인터뷰·팟캐스트에서 본인 발화 구간(URL + 타임스탬프 + 발화 요약) 20개 이상.
승인 기준: 숫자 30개 이상, 본인 발화 15개 이상, 출처 없는 행 0개

## 2단계. 대본 v1 → v3
`02_대본구조.md` 표대로 12~14챕터, 13,000자. 각 문단 끝에 [화면: ...] [클립: 인용후보 #n] [카드: 숫자] 지시 포함.
v2: 플랜팅·콜백 위치 표시, 인용 밀도 점검(20초당 1개). v3: 소리 내어 읽기용 발음교정본 생성.
승인 기준: 콜드오픈 65초 이내, 숫자 블록 존재, 콜백 3회 이상, 엔딩 2문장

## 3단계. 나레이션 (ElevenLabs)
문단 단위 mp3. 고유명사·월·금액 치환본으로 생성. 생성 후 자동자막(Whisper)으로 되읽어 원문과 대조 → 불일치 문단만 재생성.
승인 기준: 고유명사 오독 0, 총 길이 25~30분

## 4단계. 자산 수집
- 클립: 인용후보에서 구간만 잘라 `04_자산/clips/`(10초 내외, 출처 자막 자동 삽입)
- 사진: Wikimedia Commons API로 검색·다운로드, 파일명에 라이선스
- AI 재연: 대본의 [화면] 지시 중 실사 없는 것만. 프롬프트에 "silhouette, back view, no face" 고정
- 사진-장소-날짜 검증표(`QA.md`)를 여기서 작성
승인 기준: 모든 컷에 출처, 얼굴 재현 0, 틀린 장소 0

## 5단계. 리모션 그래픽
숫자 카드(검정 배경, 핑크·골드 큰 숫자, 아래 작은 설명), 챕터 카드(CHAPTER n + 제목), 타임라인(연도 축), 상승 그래프, 스코어보드.
1편 기준 숫자 카드 10장·챕터 카드 13장·그래프 2장.
승인 기준: 모든 카드의 숫자가 사실표와 일치, 글자 줄넘김 없음(강의의 "10억 이상 글자가 줄을 넘겼네" 사례)

## 6단계. 조립 → 캡컷 프로젝트
나레이션 트랙 위에 타임라인.csv대로 컷 배치, BGM(Suno, 장면 분위기별 3~4곡), 효과음(전환·숫자 등장·강조).
렌더 전에 캡컷 프로젝트로 받아 효과음 볼륨, 컷 순서를 직접 조정(강의: "효과음들이 왜 이렇게 커? 조금씩 줄여 줘").
승인 기준: 무음 구간 0, 효과음이 나레이션을 덮지 않음, 자막 줄넘김 0

## 7단계. 출시 패키지
제목 5안(30자 이내), 썸네일 3안, 설명란(2줄 요약→타임라인→출처→AI 고지→태그), 고정댓글(전체 출처 링크), 쇼츠 3개.
승인 기준: 제목에 구체 사물·숫자 훅, 썸네일 글자 2줄

## 8단계. 사후 48시간
조회수·시청 지속 그래프를 받아 이탈 지점 타임스탬프 → 다음 편 대본 규칙에 반영.
