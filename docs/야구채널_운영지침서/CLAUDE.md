# CLAUDE.md — 야구 인물 서사 채널 작업실 규칙

당신은 이 채널의 제작 직원이다. 영상 하나 = 폴더 하나. 산출물은 전부 영상 폴더 안에 남긴다.
이 채널은 야구 선수·감독의 인생에서 '숫자로 증명되는 감정'을 판다. 사건 당일 속도가 생명이다.

## 폴더
```
<선수_사건>/
  01_리서치/  사실표.md(날짜·기록·출처URL·신뢰도), 인용후보.md(본인 발화 15개: URL·타임스탬프·요약), 기록표.csv(연도별 성적)
  02_대본/    대본_v1~final.md(12~14분, 5,500~6,500자), 발음교정본.txt, 챕터표.md
  03_음성/    나레이션(문단 단위)
  04_자산/    clips/(10초 이내, 출처·타임코드), photos/(CC·구단 공개), graphics/
  05_그래픽/  remotion/(기록 카드, 타임라인, 비교 카드, 스코어보드 재현)
  06_편집/    타임라인.csv, 캡컷 프로젝트
  07_출시/    제목5안.md, 썸네일3안, 설명란.md, 쇼츠3개.md, 판정표.md
```

## 소재 규칙
- 사건형(진출·우승·탈락·은퇴·FA·기록 달성)은 사건 후 3시간 내 업로드가 목표. 24시간을 넘기면 만들지 않는다
- 인물형(평생 서사)은 모음·클립 영상 300만 이상 인물만. 선수 본인 발언 자료 15개 이상
- 각도는 하나의 숫자 대비로 잡는다(2,600경기 대 반지 0개 / 통산 1위 대 한국시리즈 0번)

## 대본 규칙
- 콜드오픈 60초: 숫자 3~4개 → 클립 5초 → 약속 문장("이건 ~한 한 선수의 이야기입니다") → 질문
- 플랜팅 1개(약속·대사)를 전반에 심고 엔딩에서 회수. 모티프 1개를 3회 콜백
- 분당 440~470자. 클립은 14블록 이하, 각 10초 이하, 반드시 해설 동반
- 숫자 블록 1개(연도별 기록 6~8장 연속 카드). 엔딩은 질문 또는 다음 경기 예고
- 모든 기록·날짜는 사실표에 출처가 있는 것만. 자료 간 불일치는 확정 전 사용 금지

## 화면 규칙 (저작권)
- KBO·TVING 중계, 공중파·종편 뉴스 화면: 전체의 30% 이하, 컷당 10초 이하. 수익 채널은 40초·비수익 규정 밖이므로 최소화
- 대체 자산: 구단 공식 채널 인터뷰(10초 인용), 선수 본인 SNS, Wikimedia·공공누리 구장 사진, 리모션 기록 그래픽(스코어보드 재현, 타임라인, 비교 카드, 궤적 도식)
- 경기 장면이 꼭 필요하면 정지 화면 1장 + 그래픽 재구성
- 썸네일: 얼굴 1 + 2줄 이내 + 강조색 1

## 출시 규칙
- 제목 24~30자, 검색 구절("강민호 우승 반지")을 맨 앞에. 메모·감상 문장 금지. TOP n 금지
- 쇼츠 1~3개 먼저(또는 동시), 쇼츠 설명란·고정댓글·관련 동영상에 롱폼 링크. 롱폼 설명란에는 쇼츠 링크를 넣지 않는다
- 설명란: 2줄 요약 → 챕터 → 출처 → AI 고지 → 태그. 자동 더빙 켜기
- 48시간 판정표를 07_출시/판정표.md에 기록
