```
리모션으로 기록 카드 6장(연도별), 타임라인 1장, 비교 카드 1장(반지 6개 vs 0개), 스코어보드 재현 2장. 검정 배경, 팀 컬러 강조 1색, 글자 줄넘김 자동 축소.
```

```
타임라인.csv에서 중계·뉴스 화면 컷을 전부 뽑아 길이 합계와 전체 대비 비율을 계산하고, 10초 넘는 컷과 30% 초과분을 그래픽 대체안으로 바꿔 줘.
```
