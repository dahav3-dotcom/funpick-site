# 03. 제작·출시 규칙

## 저작권 (야구 특수)
| 소스 | 규정·위험 | 사용 규칙 |
|---|---|---|
| KBO·TVING 중계 화면 | 40초 미만·비수익 목적만 허용(2025 단속 보도). 수익 채널은 규정 밖 | 컷당 10초 이하, 전체 30% 이하. 가능하면 정지 화면 1장 + 그래픽 |
| 공중파·종편 뉴스·인터뷰 | 방송사 저작권. 강의 기준 금지 소스 | 인용 10초 이내, 해설 동반. 대체 가능하면 쓰지 않는다 |
| 구단 공식 채널(LionsTV 등) | 저작권 있음, 인용·비평 10초 | 본인 발언 인용에만 |
| 선수 본인 SNS·본인 채널 | 인용 가능 범위 넓음 | 정지 화면·발언 |
| Wikimedia·공공누리 | 자유 | 구장·도시 사진 |
| 리모션 그래픽 | 자체 원본 | 스코어보드 재현, 타임라인, 비교 카드, 타구 궤적 도식 |
설명란 고지 고정: "경기·인터뷰 영상은 인용·해설 목적으로 10초 이내 사용. 기록은 보도 기준. 나레이션은 AI 음성."

## 쇼츠 → 롱폼 퍼널
- 사건 당일: 쇼츠 1개(결정 장면 + 질문, 끝에 "본편") → 1시간 뒤 롱폼. 쇼츠에 관련 동영상 연결, 고정댓글에 링크
- 롱폼 설명란에는 쇼츠 링크를 넣지 않는다(방향 역전 방지)
- 쇼츠는 채널 나이와 무관하게 테스트 노출을 받으므로 신규 채널의 유일한 입구

## 제목·썸네일
- 제목 24~30자, 검색 구절을 맨 앞에("강민호 우승 반지 0개, 23년 만의 마지막 한국시리즈"). 메모·감상 문장·100자 채우기 금지
- 썸네일: 얼굴 1 + 2줄 + 강조색 1. 결말 스포 금지(시리즈 결과 편 제외)

## 48시간 판정표
| 지표 | 통과 | 실패 시 |
|---|---|---|
| 노출수 | 5,000 이상 | 500 이하면 노출 문제(쇼츠 퍼널·제목 점검) |
| 클릭률 | 5% 이상 | 3% 이하면 썸네일 B안 |
| 평균 시청 지속 | 40% 이상 | 25% 이하면 콜드오픈 재편집 |
| 검색 순위(핵심 구절) | 상위 5 | 설명란 첫 2줄에 구절 삽입 |
| 쇼츠 | 채널 바닥의 4배 | 훅 교체 |
